## Reviewer test scope

[Source-pinned, read-only 10-test cross-check](../scripts/check_bosscoder_chinook_easy_25_26_year_running_contracts.py) first authenticates both saved Git blobs and detects replacement of Q26's Pending solution fields; then compares reviewer-authored 2024 month/YTD SQL with an independent Python `Decimal` invoice-level oracle. Tests include Q25's original six-invoice teaching example, full 12-month completeness, empty dataset, omitted months and forward-fill running balances, half-open 2024 boundaries/leap day, NULL totals/date, calendar aggregation vs archived Q25 month totals, and two **counterexamples**.

1. **Rounding ambiguity:** for three invoice totals of 0.004 each across January–March, sum of three *display-rounded monthly figures* is 0.00 but unrounded YTD rounded at March is 0.01. The prompt does not disambiguate whether running totals accumulate raw amounts or rounded monthly revenues. Reviewer favors raw running sum; cannot claim this as instructor grading policy.
2. **Malformed date loss:** `2024-13-01` and `2024-not-a-date` pass lexical range filtering but have NULL SQLite `strftime` month and disappear from a 12-month calendar join. Test separately confirms **two hypothetical malformed rows / 120.00 units omitted**, demonstrating need for source-data quality validation, **not** proving defects in original Chinook.
3. **Missing months/zero total semantics:** 12-row wording suggests explicit month calendar even when no invoice exists; archived Q25 historical query returns only populated months. Zero fill, all-NULL `Total`, time-zone interpretation, numeric type, and rounding order need original provider/example verification.
