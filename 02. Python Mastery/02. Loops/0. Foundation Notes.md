# Loops — Foundation Notes

**Main idea:** A loop repeats work. Use `for` when iterating over values; use `while` while a condition remains true.

## 1. For loops and range

```python
transactions = [100, 250, 300]
total = 0
for amount in transactions:
    total += amount
print(total)  # 650
```

This iterates over **values**. If you need indexes:

```python
for i in range(len(transactions)):
    print(i, transactions[i])
```

`range(start, stop, step)` includes `start`, **excludes `stop`**, and advances by `step`:

```python
print(list(range(2, 9, 2)))  # [2, 4, 6, 8]
```

**JavaScript link:** `for (const amount of transactions)` ≈ `for amount in transactions:`; Python `range()` is a number generator, not an array argument.

## 2. While loops and safe boundaries

```python
transactions = [200, 350, 500, 400]
total = 0
i = 0
while total < 1000 and i < len(transactions):
    total += transactions[i]
    i += 1
print(total, i)  # 1050 3
```

Stop at the threshold **or** the end of the list. List indexes run from `0` to `len(list) - 1`.

## 3. Break and continue

```python
transactions = [150, -20, 300, 0, 400]
total = 0
for amount in transactions:
    if amount < 0:
        continue  # skip negative value
    if amount == 0:
        break     # stop the whole loop
    total += amount
print(total)      # 450
```

- `continue`: skip the rest of the current iteration.
- `break`: exit the whole loop.

## Quick revision

- Direct iteration gives the item; `range(len(items))` gives an index.
- Always make progress toward a `while` stop condition.
- Use `i < len(items)`, not `i <= len(items)`, to avoid `IndexError`.
- Check indentation and colons carefully.

## Mentorship audit: reporting-loop patterns and bounded retries (PDF pp. 12–13; 2026-11-09)

Most data-processing loops implement **accumulate** (`total += amount`), **count** (`count += 1`), or **track best** (update a max when a larger value arrives). Initializing `biggest = amounts[0]` fails for an empty list, so check for emptiness first. `enumerate(rows, start=1)` provides a human-friendly number and the row together. `range(5, 0, -1)` generates `5,4,3,2,1`, not zero.

A retry loop should have a maximum attempt count, a success flag, and a condition that advances on each pass. Do not retry forever or claim success after exhausting attempts:

```python
attempts, connected = 0, False
while not connected and attempts < 3:
    attempts += 1
    connected = (attempts == 3)  # deterministic lesson simulation
print(attempts, connected)        # 3 True
```

For a search using `found_at = None`, check `found_at is not None` **before** indexing a list. `break` stops at the first match; `continue` skips only the current input. For nested loops, the inner body can execute approximately `outer_count * inner_count` times, which matters at scale. ## Bosscoder Refresher-1 source cross-check: `for` / `while` `else` (2026-11-10)

The preserved [Lecture-01 loop notes](<../../99. Reference Materials/Legacy Journey Snapshot/02-python/bosscoder/lecture-01/03-control-flow-and-practice.md>) include a Python-specific construct not previously explained here. A loop's `else` executes **when the loop terminates without `break`**; it does **not** mean "the final item failed an `if` test." It runs even if an iterable is empty, and `continue` alone does not suppress it.

```python
statuses = ["paid", "pending"]
for status in statuses:
    if status == "failed":
        print("Failure found")
        break
else:
    print("No failures found")  # printed for these two statuses
```

If a `"failed"` item is present, the `break` prevents the `else`. A `while` loop has the same normal-termination rule.
