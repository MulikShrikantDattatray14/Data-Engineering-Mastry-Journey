# Modules, Packages, Files and Errors — Foundation Notes

## Why learn this?

Data Engineering programs often run as multiple files: extract data, transform it and write results. Modules organize code, file handling moves data, and error handling prevents one bad record from silently corrupting a job.

## 1. Modules and packages

A **module** is a Python `.py` file. A **package** groups modules. Python's standard library already includes helpers like `csv`, `json`, `pathlib` and `datetime`.

```python
from datetime import date, timedelta
print(date(2025, 4, 1) + timedelta(days=2))
# 2025-04-03
```

**JavaScript comparison:** `import { something } from './file.js'` serves a similar purpose, though Python import/module resolution differs.

Use `python -m pip install package-name` in the right virtual environment. Do not put terminal commands inside Python code.

## 2. Reading a file safely

```python
from pathlib import Path
path = Path("orders.csv")
if path.exists():
    print(path.read_text(encoding="utf-8")[:50])
```

For larger files, stream rows instead of reading everything into memory:

```python
with open("orders.csv", encoding="utf-8") as file:
    for line in file:
        print(line.strip())
```

`with` closes the file even when an exception occurs. For real CSV containing quoted commas, use `csv.DictReader`, not naïve `split(",")`.

## 3. File modes

| Mode | Purpose | Caution |
|---|---|---|
| `r` | Read | Missing file → `FileNotFoundError` |
| `w` | Write | **Overwrites existing contents** |
| `a` | Append | Adds to file end |
| `x` | Create new | Errors if file already exists |

## 4. JSON and missing values

```python
import json
order = json.loads('{"id": 101, "amount": 200, "city": null}')
print(order["city"] is None)  # True
print(json.dumps({"ok": True})) # {"ok": true}
```

JSON `null` maps to Python `None`, JSON `true` maps to Python `True`. `json.load()` reads an opened file; `json.loads()` parses a string.

## 5. Errors and safe handling

```python
raw = "not-a-number"
try:
    amount = float(raw)
except ValueError:
    amount = None
print(amount) # None
```

Use specific exceptions, not a blanket `except:`. Logging invalid records can be better than silently dropping them.

## 6. Command-line entry point

```python
def main():
    print("run ETL")

if __name__ == "__main__":
    main()
```

This runs `main()` when the file is executed directly, but not when it is imported as a helper.

## Quick revision

- `pathlib.Path` is a readable cross-platform path abstraction.
- Always specify an encoding for text files.
- Avoid overwriting raw source datasets when practicing.
- Use context managers for file resources and close/cleanup.
- Guard write operations: repeated execution should not duplicate data accidentally.

## Mentorship source comparison: modules, files, JSON and project reporting (PDF pp. 20, 22–23; 2026-11-09)

**Module import:** `import helpers` runs the helper module's top-level code once per interpreter process (subject to import caching). Protect command-line work behind `if __name__ == "__main__":` so an import does not accidentally start a pipeline. Prefer `python -m pip install ...` in the correct virtual environment instead of assuming the system `pip` belongs to that interpreter. `pip freeze > requirements.txt` captures installed distributions; review dependencies before sharing a reproducible setup.

**File iteration:** `file.readline()` returns one line, often including `\n`; `file.read().splitlines()` reads all content and drops line separators. For large datasets, iterate with `for line in file:` to avoid reading everything into memory. `Path("reports").mkdir(parents=True, exist_ok=True)` safely creates nested output folders. `glob("*.json")` searches one folder, while `rglob("*.json")` searches recursively.

**Monthly store report:** A source example reads orders, excludes nondelivered rows, groups by `order_date[:7]`, and maintains `orders`, `revenue` and `best` for each month. It reports **12 delivered orders and 18,972.00 revenue** in four months for its archived 15-row dataset. The original example uses `split(",")`; this is appropriate only for simple fixtures, not general CSV. Here is a safer *teaching adaptation* for a small quoted-CSV fixture:

```python
from csv import DictReader
from io import StringIO
csv_text = "order_id,status,amount\n101,delivered,1198.00\n102,cancelled,1999.00\n103,delivered,796.00\n"
orders = list(DictReader(StringIO(csv_text)))
delivered_total = sum(float(o["amount"]) for o in orders if o["status"] == "delivered")
print(delivered_total)  # 1994.0
```

In real ETL, also validate status, date and amount; decide how to handle duplicate IDs, missing fields, decimal currency precision and empty groups. Do not claim this three-row fixture validates the entire supplied 15-row file.
