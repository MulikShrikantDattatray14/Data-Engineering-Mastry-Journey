# Pandas for Data Engineering — Foundation Notes

## Why do we need this?

SQL transforms tables in a database; **pandas** helps manipulate tabular files and in-memory datasets in Python. Understanding the same operation in both languages makes an experienced JavaScript developer transition faster.

## 1. Tiny order dataset

| order_id | status | amount |
|---:|---|---:|
| 101 | delivered | 100 |
| 102 | cancelled | 500 |
| 103 | delivered | 200 |

Our business question: **total delivered revenue**.

## 2. SQL versus pandas

**SQL**

```sql
SELECT SUM(amount) AS revenue
FROM Orders
WHERE status='delivered';
```

**Pandas**

```python
import pandas as pd
df = pd.DataFrame([
    {"order_id":101,"status":"delivered","amount":100},
    {"order_id":102,"status":"cancelled","amount":500},
    {"order_id":103,"status":"delivered","amount":200},
])
delivered = df.loc[df["status"] == "delivered"]
print(delivered["amount"].sum()) # 300
```

## 3. Watch the rows change

```text
RAW (3 rows)                         FILTERED (2 rows)
101 delivered 100       ───────→     101 delivered 100
102 cancelled 500       [removed]    103 delivered 200
103 delivered 200                    ────────────────
                                     SUM = 300
```

## 4. Important pandas concepts

| Goal | Pandas approach |
|---|---|
| Load CSV | `pd.read_csv(path)` |
| Inspect rows | `df.head()`, `df.shape` |
| Filter rows | `df.loc[condition]` |
| Select columns | `df[["a","b"]]` |
| Group/aggregate | `df.groupby("status")["amount"].sum()` |
| Join datasets | `df.merge(other, on="id", how="left")` |
| Handle null | `df.isna()` and careful `fillna()` |

## 5. Dangerous mistakes

- Missing values aren't automatically zero. Filling NULL with zero changes some business metrics.
- `merge()` with duplicate keys can **multiply rows**, just like SQL joins.
- Pandas is **in-memory** for many operations; a CSV larger than memory may require chunked streaming, Spark or a database.
- Date strings should be parsed into date types before extracting months.
- Avoid slow row-by-row Python loops when vectorized pandas operations can do the work efficiently.

**JavaScript analogy:** A DataFrame is not merely `Array<Object>`; pandas provides typed column operations, vectorization and index alignment, with different missing-value semantics.
