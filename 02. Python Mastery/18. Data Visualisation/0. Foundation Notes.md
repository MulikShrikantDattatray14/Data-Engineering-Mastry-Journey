## 1. Choose a plot by the analytical question

| Question | Appropriate view | Watch for |
|---|---|---|
| How did daily delivered revenue change? | Line plot | Sort by actual date and include missing days deliberately |
| How do categories compare? | Bar chart | Consistent units and meaningful baseline |
| Is numerical data skewed? | Histogram | Bin width changes the story |
| Are two numerical variables related? | Scatter plot | Correlation does not establish cause |
| How do groups vary? | Box or violin plot | Outliers, sample size and distribution shape |
| How do numerical features relate? | Heatmap of correlation | Nonlinear relationships and confounding |
| Which pairwise relations deserve inspection? | Pair plot | Many columns can create expensive clutter |
| How does a composition break down? | Pie chart, sparingly | Hard to compare similar fractions |

## 2. A small matplotlib example

```python
import matplotlib.pyplot as plt

months = ["Jan", "Feb", "Mar", "Apr"]
revenue = [1994, 2847, 7291, 6840]
fig, ax = plt.subplots()
ax.plot(months, revenue, marker="o")
ax.set(title="Delivered revenue", xlabel="Month", ylabel="Revenue (INR)")
fig.tight_layout()
# Display interactively or save in the caller's chosen reports folder.
```

Keep chart generation in a reusable function when building reports. Do not silently infer a local currency from a numeric field; label the actual measurement unit and source period.

## 3. Seaborn and pandas connections

Seaborn uses a DataFrame-friendly interface for scatter, line, bar, histogram, box, violin, heatmap and pair plots. Many `sns.*plot(data=df, x=..., y=..., hue=...)` calls use long-form data. Some versions warn when `palette` is supplied without `hue`; check the installed version rather than treating plotting APIs as permanent.

Pandas Index labels need **not be unique**. Before plotting a series, decide whether duplicate date/key rows are expected observations or errors. Notebook cells may mutate `df` or plotting state; source-aligned examples should create fresh fixtures instead of assuming hidden earlier execution.

## 4. Data-engineering checks before plotting

- Validate source timestamp types and normalize timezone before daily bucketing.
- Decide whether missing data is zero, unknown or an actual absence.
- For ratios, use meaningful denominators and handle zero denominators.
- Avoid misleading category sorting or truncated axes.
- Reconcile totals and check duplicates after joins before charting.
- Never publish production customer details, card numbers or sensitive data in sample visuals.
